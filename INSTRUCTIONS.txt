HOW TO USE THE APPLICATION
===============================================================================

1. ENTER PASSENGER INFORMATION
   - Name: Type passenger's full name
   - Gender: Select Male or Female
   - Age: Enter passenger's age (0-120)
   - Category: Choose One, Two, or Three
   - Distance: Enter travel distance in kilometers

2. CLICK "CALCULATE" BUTTON
   - The system will validate all inputs
   - Price will be calculated automatically
   - A summary window will appear showing the final price

3. VIEW TICKET SUMMARY
   - Passenger details will be displayed
   - Final price shown after discounts
   - Click OK to close the summary

4. USE "CLEAR" BUTTON
   - Clears all input fields
   - Ready for next calculation

5. USE "EXIT" BUTTON
   - Confirmation dialog appears
   - Click Yes to exit the application

===============================================================================
PRICING RULES
===============================================================================

CATEGORY PRICING:
-----------------
Category One   → R20 per kilometer
Category Two   → R35 per kilometer
Category Three → R50 per kilometer

DISCOUNT RULES:
--------------
Age < 12 years → Ticket is FREE (R0.00)
Female         → 50% discount applied

CALCULATION:
-----------
Base Price = Category Rate × Distance
Final Price = Base Price (after age and gender discounts)

===============================================================================
TROUBLESHOOTING
===============================================================================

PROBLEM: Project won't open in Visual Studio
SOLUTION: 
- Ensure you're opening the .sln file, not the .csproj
- Update Visual Studio to the latest version
- Install .NET Framework 4.7.2 or later

PROBLEM: Build errors appear
SOLUTION:
- Right-click on the solution
- Select "Clean Solution"
- Then select "Rebuild Solution"

PROBLEM: Form doesn't display
SOLUTION:
- Close and reopen Form1.cs in the designer
- Rebuild the project
- Check that all .resx files are included

PROBLEM: Application crashes on calculation
SOLUTION:
- Verify all inputs are valid
- Check that validation logic is working
- Look at the error message for details
